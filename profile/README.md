## Getting Started

### Prerequisites

- **Git** - [Download Git](https://git-scm.com)
- **Text Editor** - VS Code, Sublime Text, or any editor of your choice
- **Web Browser** - For testing (Chrome, Firefox, Safari, or Edge)
- **GitHub Account** - [Create an account](https://github.com/signup)

### Quick Start

1. **Explore our repositories**
   ```bash
   # Visit: https://github.com/Prince-Albert-Islamic-Association
   ```

2. **Fork a project** that interests you
   ```bash
   # Click the "Fork" button on the repository page
   ```

3. **Clone your fork**
   ```bash
   git clone https://github.com/YOUR-USERNAME/project-name.git
   cd project-name
   ```

4. **Create a feature branch**
   ```bash
   git checkout -b feature/your-feature-name
   ```

5. **Make your changes** and commit
   ```bash
   git add .
   git commit -m "feat: describe your changes"
   ```

6. **Push to your fork**
   ```bash
   git push origin feature/your-feature-name
   ```

7. **Submit a Pull Request** to the main repository

## How to Contribute

We welcome contributions from everyone! Whether you're a seasoned developer or just starting out, there's a place for you here.

### Types of Contributions

✨ **Code** - Submit bug fixes, features, or improvements  
📝 **Documentation** - Help us improve our guides and README files  
🐛 **Bug Reports** - Found an issue? Let us know!  
💡 **Ideas** - Have a suggestion? Open a discussion!  
🎨 **Design** - Contribute UI/UX improvements  

### Contribution Guidelines

1. **Fork** the repository
2. **Create a branch** with a descriptive name
3. **Make your changes** with clear, meaningful commits
4. **Test** your work thoroughly
5. **Submit a Pull Request** with a detailed description
6. **Engage** with feedback and iterate

### Code of Conduct

- Be respectful and inclusive
- Provide constructive feedback
- Focus on the issue, not the person
- Help others learn and grow
- Respect our Islamic values and community standards
